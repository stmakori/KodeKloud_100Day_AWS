# KodeKloud 100 Days of AWS Challenge

This repository is structured to document progress for the **KodeKloud 100 Days of AWS Challenge** in a clean, repeatable way.

## Repository Structure

```text
.
├── README.md
└── docs
    ├── README.md
    ├── templates
    │   └── day-template.md
    └── day-001
        └── README.md
```

## How to Use This Structure

1. Use `docs/templates/day-template.md` as the base for every day.
2. Create a new folder per day using the format `docs/day-XXX/` (for example, `docs/day-002/`).
3. Add that day’s notes in `docs/day-XXX/README.md`.
4. Update `docs/README.md` tracker with links to completed days.

## Naming Convention

- Day folder: `day-001`, `day-002`, ..., `day-100`
- Main daily file: `README.md` inside each day folder

This keeps your challenge documentation easy to navigate and scalable for all 100 days.
